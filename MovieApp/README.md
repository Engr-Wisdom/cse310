# StudentTaskPlanner

## Overview

As a software engineer, I am continually improving my software development skills by learning modern mobile application development with React Native and Expo.

**StudentTaskPlanner** is a mobile application that helps students organize and manage their academic work. The application allows users to create courses, organize assignments by week, track assignment progress, and store data locally so that information remains available even after the application is closed.

The purpose of creating this software was to learn how to:

- Build mobile applications using React Native and Expo
- Implement navigation between multiple screens
- Manage application state using React Context
- Store data locally using AsyncStorage
- Create a responsive and user-friendly interface

## Features

- Create and manage multiple courses.
- Organize assignments into seven weekly sections.
- Add assignment titles, descriptions, priorities, and due dates.
- Mark assignments as completed.
- Track assignment progress using a progress bar.
- Delete courses.
- Delete assignments.
- Store application data locally using AsyncStorage.
- Provide a responsive mobile user interface.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Elilaw179/cse310.git
```

Navigate to the project directory:

```bash
cd StudentTaskPlanner
```

Install the project dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```
